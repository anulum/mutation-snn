# Architecture

## Current executable surface

Repository validation tooling, dedicated tests, workflow definitions and native documentation are implemented. No domain registry, source adapter, patch generator, runner, classifier, statistical backend, report or product command is installed. Domain capability, claim and qualified-format inventories remain empty.

## Intended data flow

An earlier complete campaign selects target, suite, source, operator protocols, generated identities, baseline, assertions, random state, resource bounds and finality policy. Source-preserving patches feed actual owned execution adapters. Complete attempts feed attribution, independently scoped equivalence, whole counts, finite metrics, survivor partition and only separately admitted inference. Native candidates use shared evidence operations and a separate current consumer.

## Ownership and interpretation

Mutation SNN owns mutation campaigns and source-bound outcome analysis. SC-NeuroCore and evaluated suite owners retain their source. Divergence Harness owns the independent oracle, reducer and regression corpus. Evidence Manifest Toolkit owns shared evidence operations. Studio renders sealed counts and findings.

Exact source and population identity are required. Changed source requires a new baseline and population. No output chooses its own method or favourable subset. Read [the documentation architecture](docs/ARCHITECTURE.md).
