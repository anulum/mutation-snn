# Repository architecture

## Current executable tooling

Metadata, source-provenance, workflow, dependency-alignment, documentation, inventory and preflight controls inspect declared local scopes. Native bootstrap checks selected executable and licence files. Received metadata cannot select policy or grant mutation adequacy. Foundation qualification is in progress.

## Intended campaign boundaries

| Component | Responsibility | Required evidence |
| --- | --- | --- |
| Registry | Select a source-specific operator protocol | Full identity, typed controls, admitted actual source and independent isolation witness |
| Generation | Freeze the unique population and exact patches | Before/after source, unchanged-state scope, immutable IDs and original suites |
| Execution | Exercise the unmodified baseline and each bounded mutant | Actual owning adapters, complete assertions, resources, random state and all attempts |
| Classification | Attribute outcomes and scoped equivalence | Baseline validity, independent failures, actual assertion difference and independent proof |
| Analysis | Recompute complete counts, finite metrics and survivor partition | All unique IDs, all planned classes, denominators and complete outcome tuples |
| Evidence | Produce the full native candidate and separate verification | Same source and population, admitted method, shared evidence and independent consumer |

The prospective native report has twelve required properties: schema_id, claims, source_ref, environment_ref, target_suite, target_model, baseline_passed, operator_set, mutants, class_counts, statistics and survivor_clusters. This declaration is not registered or qualified support.

Five prospective operations are generate, run, analyse, report and verify. None is installed. Actual operator protocols select subtype controls before results; received values cannot choose their method. Preserve the five classes: temporal, structural, numerical, sc_specific and rtl. Weight, threshold and bias changes belong to structural; numerical changes concern representation, precision, rounding and actual overflow. Conflicting earlier parameter definitions require an explicit complete migration.

Every mutation must change only the intended actual target semantics or receive an explicit no-op, equivalent or unsupported disposition. An unused parameter, unequal seeds or a fabricated RTL site cannot establish isolation. Source-sharing requires full stream, state and coupling context. RTL simulation binds actual generated source and instantiated sites; physical placement remains a later measured lane.

The unmodified baseline must pass the complete frozen public suite. A kill requires a previously passing assertion to fail because of the intended change. Independent build or runner failure is invalid_error, bounded unfinished assertions are timeout, a passing executable survives unless independently justified equivalent. Missing or cancelled observations stay incomplete. Passing a suite is not an equivalence proof.

Every final generated unique mutant appears once. Retain all attempts; do not count attempts as new mutants. Same-source continuation preserves terminal rows and executes pending identities only under identical complete context. Changed source or suite requires a new baseline and population. Any retry policy is an earlier finite choice that changes the estimand; retain unresolved attempts and do not choose the best result.

Emit every planned class, including zero-member classes. Resolved score is exact K/(K+S), unavailable at zero denominator. A proposed unresolved descriptor (timeout+invalid_error)/N requires explicit definition adoption; justified equivalents remain separately visible. The closed report has no overall-score field. Finite score alone supplies no universal suite-adequacy verdict.

Clusters partition actual survivors by complete ordered assertion-outcome tuples. Missing outcomes are not passes. Deterministic cluster order does not establish behavioral relevance; an independent scoped witness is required.

Finite data has no inferential confidence, alpha or power. Independent Bernoulli, whole-campaign distribution, independent Welch equivalence, evidenced paired equivalence and prospective joint-decision power retain separate source-law and numerical prerequisites. Hand-selected dependent mutants are not independent trials. Retry conditioning, failed and unknown campaigns, stopping, margins and simultaneous uncertainty remain part of the declared estimand.

Shared evidence and current verification cannot turn a source specimen into an executed, simulated or measured result. Studio displays denominators, operator versions, equivalence and unresolved counts without reclassification. Downstream safety, quality and deployment consumers apply their own admitted scope.
