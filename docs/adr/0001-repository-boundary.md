# Decision: preserve complete mutation populations and outcome evidence

## Context

A high score can hide omitted mutants, invalid baselines, build failures or unproved equivalence. A passing mutant does not by itself prove a defect or equivalence.

## Decision

Mutation SNN owns complete source-specific campaigns, bounded attempts, attributed outcomes, aggregate analysis and scoped reports. Evaluated source and suites, independent oracles, shared evidence and downstream eligibility retain separate owners.

## Consequences

Repository controls can be qualified before a mutation engine exists. Changed source requires fresh admission, baseline and population. Finite counts are distinct from inferential adequacy. Actual physical placement needs measured evidence, and a signature alone proves none of these conditions.
